OPEN ON WINDOWS
1. Extract the ZIP file.
2. Open the BhattiRootX333_Website folder.
3. Double-click index.html. It opens in your browser.
4. To edit text, open index.html in Notepad or VS Code.
5. To change design/colors, edit css/style.css.

BEFORE PUBLISHING
- In index.html, replace the YouTube and TikTok placeholder URLs with your actual profile URLs.
- The handle shown is @bhattirootx333. Update it if you want a different spelling.
- This is a static front-end website. It does not include a database, account login, admin dashboard or server-side contact form.
